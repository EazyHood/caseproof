# Caseproof

Status: active. Design chosen for a focused payment-reconciliation workbench.

Ivory paper `#f5f4ee`, white panels `#fffefa`, ink `#182922`, forest `#23583d`, muted ink `#57655c`, lines `#d8ded3`. Amber and red signal attention, always accompanied by a label. A dark evergreen header anchors the ledger; coral is reserved for discrepancies. No glass effects or decorative dashboard charts.

Typography: Segoe UI / system sans for controls, Georgia for the editorial heading, Consolas / system monospace for amounts and evidence identifiers. All fonts are local. Spacing uses a 4px scale. Short, literal language. A proposed action is never styled as an executed payment.

Responsive: 304px case navigation on desktop; stacked, horizontally scrollable case buttons on mobile. Always show provenance adjacent to the conclusion. Interface is intentionally light-theme only at this stage. No remote fonts, tracking or raster UI assets.
