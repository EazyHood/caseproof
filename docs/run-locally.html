LOCAL SETUP / REAL SERVICES ARE OPTIONAL

Run the full workbench.

This hosted demo only reads saved synthetic scenarios and recorded evidence. The source app can inspect PayPal sandbox orders and call an installed local model.

1. Start with the deterministic demo

Install Node.js 22 or later. Caseproof has no npm dependencies.

Open the source repository ↗

git clone https://github.com/EazyHood/caseproof.git
cd caseproof
node --test
node server.mjs

Open http://127.0.0.1:5189. The six synthetic scenarios work without accounts or credentials.

2. Enable local model proposals

Install Ollama and an appropriate model separately, then set CASEPROOF_OLLAMA_MODEL to its installed name in the server environment. The recorded evaluation used qwen3:4b-instruct-2507-q4_K_M. This app does not install models for you.

3. Inspect an existing sandbox order

Set PAYPAL_CLIENT_ID and PAYPAL_CLIENT_SECRET in the server environment. Keep secrets out of browser code and source control. Read the repository documentation before enabling any explicit CLI payment operation. The web inspection itself does not create or capture an order.

The AI explanation remains unverified prose even when its structured checks pass. All sandbox funds are fictitious.
